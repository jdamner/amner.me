title: React

I specialise in building user interfaces with [React](https://react.dev). Its component-based approach makes it possible to create clear, reusable interfaces, while its declarative model works especially well for rich, interactive applications.

I have experience building **headless frontends** that consume APIs, as well as React interfaces for internal tools. I’ve worked with frameworks such as [Next.js](https://nextjs.org/) and use React in this site too, which is built with [Vite](https://vite.dev).

I enjoy working across the frontend and backend boundaries, keeping interfaces accessible and maintainable and making sure the data flow between a React application and its services is robust.
