title: Cloud Native
---

I’m interested in cloud-native ways of building and delivering software: using managed services where they make sense, automating deployments and designing for reliability and scale. My experience includes AWS serverless functions and delivering static sites to a CDN.

I’ve worked with GitHub Actions and Azure Pipelines to automate build, test and deployment workflows. I take a pragmatic approach, choosing infrastructure and deployment patterns that fit the needs of the application and the team.
