title: Node.js & TypeScript
---

I build full-stack applications with **Node.js and TypeScript**, using a shared language across server-side services and React frontends. TypeScript helps make application boundaries and data contracts clearer, while Node.js provides a flexible foundation for APIs and integrations.

I enjoy working across the full request flow: shaping an API, connecting it to the frontend, and making sure the resulting application is practical to test, maintain and deploy.
