I've rebuilt this site a few times over the years, exploring different ways to publish it. Today it is a **React and TypeScript application built with [Vite](https://vite.dev)**. That combination gives me the frontend tools I enjoy using, without adding a content platform or server that this particular site doesn't need.

The content lives alongside the code as MDX files. That keeps writing straightforward, while letting me compose the pages from React components and keep the presentation under my control. I can use the same development workflow for the site as I use for modern frontend applications, and make changes with a quick local feedback loop.

WordPress is still a great choice for projects that need its editing experience, extensible CMS, or eCommerce features. For my portfolio, I don't need a database-backed publishing system or an administrative interface. I mostly need a place to write, a React application to present it, and a reliable way to publish updates.

Vite builds the application into static assets that can be served by GitHub Pages. GitHub Actions runs the build and deploys the result, so there is no application server to maintain. The setup is small, familiar, and fits how I want to work on this site: using React and TypeScript, with the flexibility to keep improving it as my skills and interests evolve.
